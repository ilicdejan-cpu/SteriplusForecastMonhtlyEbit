# Notizen – dein zweites Gehirn

Dieser Ordner liegt im GitHub-Repo `steriplusforecastmonhtlyebit` und ist als
Obsidian-Vault gedacht. Er soll alle Notizen, Projektinfos und Anfragen an
einem Ort sammeln, versioniert über Git.

## Struktur

- `Projekte/` – eine Markdown-Datei pro Projekt (Status, Ziele, offene Punkte,
  Historie)
- `Anfragen/` – eine Markdown-Datei pro Anfrage (Kunde/Absender, worum es
  geht, Status, nächste Schritte)
- `_Vorlage-Projekt.md` / `_Vorlage-Anfrage.md` – Vorlagen für neue Einträge
- `00-Übersicht.md` – Übersicht/Index mit Links zu allen Projekten und
  Anfragen (Obsidian "Map of Content")

## So nutzt du es in Obsidian

1. Repo lokal klonen (oder den bestehenden Ordner öffnen), z. B.:
   `git clone https://github.com/ilicdejan-cpu/steriplusforecastmonhtlyebit.git`
2. In Obsidian: "Open folder as vault" → den Ordner `Notizen/` auswählen.
3. Änderungen in Obsidian machen, danach in Git committen/pushen, damit
   nichts verloren geht.

## Wie du mich (Claude) einbindest

Schick mir einfach laufend Infos zu Projekten oder Anfragen (Status-Updates,
neue Kontakte, Deadlines, Entscheidungen). Ich lege dann neue Notizen an,
aktualisiere bestehende und halte `00-Übersicht.md` aktuell – wie ein
persönlicher Notiz-Assistent.
